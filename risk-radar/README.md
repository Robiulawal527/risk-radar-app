# Risk Radar Frontend Upgrade

Copy these files into your existing `risk-radar` Expo folder.

Install extra packages:
```bash
npx expo install expo-router react-native-safe-area-context react-native-screens react-native-maps expo-location expo-linear-gradient react-native-svg
npm install axios @react-native-async-storage/async-storage lucide-react-native
```

Edit `src/api.ts` and replace `YOUR_LAPTOP_IP` with your computer IPv4 address.

Run:
```bash
npx expo start
```
